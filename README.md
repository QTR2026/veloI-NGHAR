# VELORA — دليل الإعداد والنشر

متجر إلكتروني نسائي (تجميل، عطور، أزياء) بتصميم فاخر داكن بلمسات ذهبية، RTL بالكامل،
متجاوب مع الهاتف والكمبيوتر، مبني بـ HTML/CSS/JS بدون أي أدوات بناء (Build tools) — جاهز للنشر على GitHub Pages مباشرة.

## هيكل الملفات

```
velora/
├── index.html          ← الصفحة الرئيسية (نقطة الدخول لـ GitHub Pages)
├── product.html         ← صفحة منتج مستقلة
├── cart.html             ← صفحة السلة وإتمام الطلب عبر واتساب
├── admin.html            ← لوحة الإدارة (منفصلة عن المتجر)
├── css/
│   ├── style.css         ← تصميم المتجر
│   └── admin.css         ← تصميم لوحة الإدارة
└── js/
    ├── firebase-config.js  ← إعدادات Firebase (عدّليها أولًا)
    ├── store.js             ← منطق مشترك: المنتجات + السلة
    ├── main.js               ← تفاعلات الهيدر ودرج السلة
    ├── home.js                ← منطق الصفحة الرئيسية
    ├── product.js              ← منطق صفحة المنتج
    ├── cart.js                  ← منطق صفحة السلة + واتساب
    └── admin.js                  ← تسجيل الدخول وإدارة المنتجات
```

## 1) إنشاء مشروع Firebase

1. اذهبي إلى https://console.firebase.google.com وأنشئي مشروعًا جديدًا.
2. من القائمة الجانبية: **Build > Firestore Database > Create database**، واختاري وضع **Production**.
3. من **Build > Authentication > Sign-in method**، فعّلي **Email/Password**.
4. من **Authentication > Users**، أضيفي مستخدمًا واحدًا يدويًا (بريد إلكتروني + كلمة مرور) — هذا سيكون حساب دخول الإدارة. لا يوجد تسجيل حسابات جديدة من الموقع، لأن الإدارة يجب أن تبقى محصورة بكِ.
5. من **Project settings ⚙️ > General > Your apps**، أضيفي تطبيق ويب (</> Web app) وانسخي بيانات `firebaseConfig`.

## 2) ربط المشروع بالكود

افتحي `js/firebase-config.js` والصقي بياناتكِ بدلاً من القيم التجريبية:

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

وفي نفس الملف عدّلي رقم واتساب المتجر:

```js
export const WHATSAPP_NUMBER = "9665xxxxxxxx"; // بدون + وبدون صفر البداية
```

## 3) قواعد أمان Firestore

من **Firestore Database > Rules**، استبدلي القواعد بما يلي، ثم اضغطي **Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /products/{productId} {
      allow read: if true;                 // الزوار يمكنهم القراءة فقط
      allow write: if request.auth != null; // الإضافة/التعديل/الحذف لمن يسجل دخول فقط
    }
  }
}
```

بهذا لا يستطيع أي زائر إضافة أو حذف منتجات — فقط من يسجل الدخول من `admin.html`.

## 4) رفع المشروع إلى GitHub Pages

1. أنشئي مستودع (repository) جديد على GitHub وارفعي محتويات مجلد `velora/` بحيث يكون
   `index.html` في **أعلى مجلد النشر مباشرة** (وليس داخل مجلد فرعي).
2. من إعدادات المستودع: **Settings > Pages**، اختاري الفرع (عادة `main`) والمجلد `/ (root)`، ثم احفظي.
3. بعد دقيقة أو دقيقتين سيصبح موقعك متاحًا على:
   ```
   https://username.github.io/repo-name/
   ```
   (استبدلي `username` و `repo-name` باسم حسابك ومستودعك).

## 5) رابط لوحة الإدارة

لوحة الإدارة تعمل كصفحة مستقلة غير مرتبطة من قائمة تصفح المتجر (لا تظهر للزوار)، ورابطها:

```
https://username.github.io/repo-name/admin.html
```

احتفظي بهذا الرابط لنفسك فقط. تسجيل الدخول محمي بـ Firebase Authentication، وحتى لو
عرف أحد الرابط لن يستطيع إضافة أو حذف أي شيء بدون بيانات دخول صحيحة، بفضل قواعد Firestore.

## 6) إضافة أول منتج

1. افتحي رابط `admin.html` وسجّلي الدخول بالحساب الذي أنشأتِه في الخطوة 1.
2. من نموذج "إضافة منتج جديد" أدخلي: الاسم، السعر، التصنيف، رابط صورة (يمكنكِ رفع الصورة
   إلى أي مستضيف صور مجاني مثل imgbb.com أو استخدام رابط مباشر)، والوصف.
3. لإظهار المنتج ضمن "مختارات VELORA" في الرئيسية، فعّلي خيار "منتج مختار".
4. لإظهاره ضمن "عروض حصرية"، فعّلي خيار "عرض" وأدخلي "السعر قبل الخصم".
5. المنتج سيظهر فورًا لكل زوار الموقع دون الحاجة لإعادة نشر أي شيء، لأنه محفوظ في Firestore.

## ملاحظات

- الصور تُدخل كروابط (URL) وليست رفع ملفات، لإبقاء المشروع بسيطًا وقابلًا للنشر على
  GitHub Pages بدون أي خادم خلفي. يمكن لاحقًا إضافة Firebase Storage لدعم رفع الصور مباشرة إذا رغبتِ.
- السلة تُحفظ في متصفح الزائر (localStorage)، وإتمام الطلب يرسل تفاصيل السلة كرسالة جاهزة
  إلى واتساب المتجر، دون معالجة دفع إلكتروني.
- التصميم متجاوب بالكامل مع الهواتف وأجهزة الكمبيوتر ويدعم التنقل بلوحة المفاتيح.
